## 전체 그림

```
배포 완료 ✅  →  1. 서치콘솔 등록  →  2. 트래픽 쌓기  →  3. 애드센스 신청/승인  →  4. 광고 삽입
```

광고 수익 = 방문자 수 × 광고 단가. 그래서 **트래픽 확보가 전부**다.
수익 공식보다 "어떻게 방문자를 모으냐"가 승부처.

---

## 1단계. Google 서치 콘솔 등록

검색엔진(구글)이 사이트를 수집·노출하게 만드는 첫 단추.

### 할 일
1. https://search.google.com/search-console 접속 → 로그인
2. 속성 추가 → **URL 접두어** 방식 선택 → `https://comment-studio-gilt.vercel.app` 입력
3. 소유권 확인 — **HTML 태그** 방식 선택 (`<meta name="google-site-verification" ...>` 제공됨)
   - 이 메타 태그 값을 받아오면 **코드에 넣는 작업은 Kiro가 대신 처리 가능**
   - (`src/app/layout.tsx`의 `metadata.verification.google`에 추가)
4. 확인 완료 후 → **Sitemaps** 메뉴 → `sitemap.xml` 제출
   - 제출 주소: `https://comment-studio-gilt.vercel.app/sitemap.xml`

### 체크리스트
- [ ] 서치콘솔 속성 추가
- [ ] 소유권 메타 태그 코드에 반영 (Kiro)
- [ ] sitemap.xml 제출
- [ ] 색인 생성 요청 (URL 검사 도구로 메인 페이지 요청)

> 참고: 색인(검색 노출)까지는 보통 며칠~몇 주 걸린다.

## 2단계. 트래픽 쌓기

애드센스는 **어느 정도의 방문자와 콘텐츠**가 있어야 승인된다.
"유령 사이트"는 반려되므로, 신청 전에 실제 사용 흔적을 만든다.

### 유입 경로
1. **SEO (장기)**
   - 타겟 키워드: "유튜브 댓글 생성기", "인스타 댓글 만들기", "디시 댓글 생성기",
     "가짜 댓글 생성기", "댓글 짤 만들기"
   - 이미 메타태그/키워드는 반영됨. 색인되면 점진적으로 유입.
2. **직접 공유 (단기, 즉효성)**
   - 짜집기/밈 제작 커뮤니티, 관련 카페, 디스코드 등에 소개
   - 본인 유튜브 채널/커뮤니티 탭에 "제작에 쓰는 툴"로 공유
3. **콘텐츠 보강으로 체류시간 ↑**
   - 사용법 안내, 예시 이미지 등을 추가하면 SEO·승인에 유리

### 체크리스트
- [ ] 커뮤니티 1~2곳에 공유
- [ ] 본인 채널/SNS에 공유
- [ ] (선택) 사용법/예시 섹션 추가
- [ ] 방문자 수 추이 관찰 (서치콘솔 + 추후 애널리틱스)

> 목표 감: 광고가 "의미 있는 돈"이 되려면 월 수만 방문 이상 필요.
> 초기에는 승인 요건을 채울 최소한의 꾸준한 방문이 목표.

## 3단계. Google 애드센스 신청 / 승인

### 전제 조건 (이미 충족한 것 ✅ / 남은 것 ⬜)
- ✅ 공개 도메인 (Vercel 배포)
- ✅ 개인정보처리방침 페이지
- ✅ 이용약관 페이지
- ⬜ 어느 정도의 콘텐츠·트래픽 (2단계 결과)

### 할 일
1. https://adsense.google.com 접속 → 사이트 등록
   - 사이트: `comment-studio-gilt.vercel.app`
2. 애드센스가 주는 **확인용 코드 스니펫**을 사이트 `<head>`에 삽입
   - **이 작업은 Kiro가 대신 처리 가능** (`layout.tsx`에 Script 삽입)
3. 심사 대기 (수일~수주)
4. 승인되면 광고 단위 생성

### 체크리스트
- [ ] 애드센스 계정/사이트 등록
- [ ] 확인용 코드 삽입 (Kiro)
- [ ] 심사 통과
- [ ] 반려 시 사유 확인 후 보완 (콘텐츠 부족이 흔한 사유)

## 4단계. 광고 코드 삽입

승인 후 실제 광고를 배치하는 단계. **UX를 해치지 않는 위치**가 핵심.

### 배치 원칙
- 생성/미리보기 영역은 **깨끗하게 유지** (광고가 가리면 바로 이탈)
- 상단 배너, 하단, 사이드(데스크톱) 위주로 배치
- 모바일에서 과도한 광고 지양 (이탈·정책 위반 위험)

### 할 일 (Kiro가 처리 가능)
- [ ] 애드센스 스크립트를 `layout.tsx`에 로드
- [ ] 광고 단위 컴포넌트 생성 (`<AdUnit slot="..." />`)
- [ ] 페이지 상/하단에 배치
- [ ] 자동 광고 vs 수동 배치 결정

## 수익 참고치 (추정, 보장 아님)

RPM(1,000뷰당 수익) 한국 기준 보수적 $1 ~ 중간 $2.5 가정.

| 월 방문자 | 월 PV(≈) | 월 수익(≈, 중간 RPM) |
|---|---|---|
| 1만 | 1.7만 | 약 6만원 |
| 3만 | 5만 | 약 17만원 |
| 5만 | 8.5만 | 약 30만원 |
| 10만 | 17만 | 약 60만원 |

- 단일 기능 툴이라 RPM은 낮은 편. 보수~중간값을 현실값으로 볼 것.
- 제작·운영비가 거의 0이라 ROI는 좋음. "밑져야 본전" 구조.
